## Context

Act as a fresh Sol/high validator, independent of T001-T004 implementation workers. Review the
finished diff and evidence through three explicit lanes, then remediate every actionable in-scope
finding and rerun the complete gate.

Lane 1 — public API and Serde:

- impossible/ambiguous states, `NonZeroU64`, empty `Only`, defaults/builders;
- legacy default/disabled/selective/nested batch semantics;
- current-only canonical writes and readable errors;
- `0.2` deprecation/export/rustdoc consistency.

Lane 2 — performance evidence:

- batch path truly avoids discarded full-report allocations rather than clearing them later;
- Criterion cases are matched and checksummed;
- DHAT cases are isolated and compare pre-change baseline with host/toolchain metadata;
- memory comparison reports absolute/relative deltas and fails only for missing, invalid, or
  incomparable evidence;
- no invented percentage is treated as a spec pass/fail gate; the existing non-failing 7% Criterion
  summary, if shown, is explicitly descriptive only;
- noisy evidence is patiently rerun in the same environment, and repeatable regressions or results
  contradicting the compact-allocation premise have an explicit owner decision before completion.
- correctness and deterministic SingleThread/Rayon behavior pass as hard gates regardless of the
  performance evidence or owner performance decision.

Lane 3 — determinism/concurrency:

- seed derivation and complete unique run indices;
- explicit sorting and sequential `f64` fold;
- SingleThread/Rayon equality and no-feature fallback;
- unchanged state, event, final-result, assertion, artifact, and public report contracts.

Do not accept prior worker self-review as this task's evidence. If a lane finds a bug, add a focused
regression test before or with the fix. Do not broaden into compiled-plan, checked-authoring, macro,
or numerical-algorithm redesign.

## DoD

- All three lanes have explicit evidence and no unresolved actionable finding.
- Any issue found is fixed within scope with a regression test and re-reviewed.
- No temporary benchmark/adapter/tracer/prototype artifacts remain.
- Machine validator, full default/all-feature/doc gates, and saved-baseline comparisons pass.
- Final review confirms every R001-R012 traceability row has concrete evidence.

## Escalate If

- A requirement lacks executable/reviewable evidence after inspecting all named paths.
- Baseline provenance is missing or was captured after the compact-path change.
- Correctness requires changing simulation math, public report fields, event order, or 037's plan
  contract.
- Repeatable performance regressions or evidence contradicting the compact-allocation premise remain
  after same-environment reruns and investigation without an explicit owner decision.
