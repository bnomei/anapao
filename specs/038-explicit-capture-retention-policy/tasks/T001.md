## Context

Spec 037/T004 is a hard prerequisite. Before any edit, read
`specs/037-compiled-scenario-trust-boundary/tasks/T004.md` and require its frontmatter to contain
exactly `status = "done"` and `verification_status = "passed"`. Only after both predicates are
present may the worker read the finalized `src/plan.rs` accessors and module visibility or edit this
task's scope. Consume that private plan contract; do not restore direct public compiled fields or
public raw engine/batch entrypoints.

Replace the five legacy capture fields with:

```rust
CaptureSchedule::{None, Final, Every { stride: NonZeroU64, include_initial, include_final }}
Selection::{None, All, Only(BTreeSet<_>)}
CaptureConfig with private schedule/nodes/metrics/variables/transfers fields
```

Mark both enums `#[non_exhaustive]`. Use tagged schedule and adjacently tagged selection Serde.
`Only(empty)` is invalid. Config fields stay private; provide read-only accessors and `#[must_use]`
consuming builders.
`CaptureConfig::default()` retains every step/all channels; `none()` returns empty snapshots,
variables, transfers, and series but always retains terminal node/metric maps. `final_only()` retains
final step channels and no transfers. Keep `disabled()` deprecated as an alias of `none()` for the
`0.2` source transition, but remove it from active examples.

Implement typed current/legacy wire intermediates. Legacy empty node/metric sets mean all; legacy
variables/transfers are all; a positive interval always maps to `Every` even when both include flags
are false; zero fails. Serialize only canonical current fields.

Refactor the shared engine transition loop around a private static full-report collector. Schedule
applies to node/metric/variable snapshots; transfer selection applies independently. Event emission
is orthogonal: default and none retention must emit identical live simulation/assertion events.
Validate Only selections against plan nodes, resolvable/tracked metrics, scenario variable names,
and edges before a partial streamed result is observable.

Keep `BatchRunTemplate.capture` temporarily functional in this task so the repository is green;
T002 replaces it with the separate aggregation contract. Do not add a second simulation loop.

## DoD

- Public typed policy, constructors, `#[must_use]` consuming builders, exports, and rustdoc exist.
- Current and legacy single-run capture JSON vectors pass and canonical output has no legacy keys.
- The full collector handles all/none/only/final/every for all four diagnostic channels.
- `none()` has empty diagnostics and populated terminal maps.
- Streaming under none retention produces the same ordered events as default retention.
- Direct legacy capture field usage in compiled README/snippet examples is migrated.
- Every internal/test/benchmark call to deprecated `CaptureConfig::disabled()` is migrated to an
  explicit final policy so `-D warnings` remains green; the deprecated method remains only as API
  compatibility and its focused compatibility test.
- All targets remain green while batch still uses the full-report path.
- A fresh Sol/high validator independently reviews the public API/Serde mapping and event-retention
  separation before the task is accepted.
