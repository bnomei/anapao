## Context

Act as a fresh independent Sol/high validator after T001-T005 are complete. Do not accept task
self-review as evidence. Review the public Rust API, stable serde document shape, conversion error
order, duplicate semantics, nonzero boundaries, and full DTO-to-checked-to-plan-to-engine data
flow. Confirm the implementation honors the completed 037 facade and module privacy.

Public API review must check complete family coverage, private checked fields, non-exhaustive new
enums, conventional builder usability in loops and chains, coherent re-exports, custom `must_use`
diagnostics, and the absence of a second serde schema.

It must compile the frozen spellings verbatim: all 15 `ScenarioNode` family constructors and common
`with_label/with_initial_value/with_tag/with_metadata`; `ScenarioEdge::{resource,state}` and
`with_enabled/with_metadata`; `ResourceConnection::default().with_token_size(NonZeroU64)`;
`StateConnection::{default,new,with_role,with_formula,with_target,with_resource_filter}`; every
field-named checked config default/setter/clearer; and the complete `ScenarioBuilder` API. Reject
renames, omitted methods, private access, or macro-only helpers before 040 consumes the surface.

Serde review must compare the frozen valid fixtures and existing serde tests, including omitted
node config, omitted default resource connection, `target_edge`/`filter` aliases, default `+1`, and
value-preserving checked round trip. The equality baseline is serialization of the parsed
`ScenarioSpec`, not raw fixture `Value`; confirm the tests do not promise raw alias/default spelling.

Cross-module review must prove map-key/ID validation happens before indexes, the plan owns checked
node/edge projections and positive values, engine decisions never use preserved DTO tags/payloads,
and all named runtime repair branches are gone. Run every validation command, not a reduced smoke
set.

Parse-once review must trace every active formula kind. Confirm DTO conversion and builder build use
one `ExprRuntime`, retain each resource-connection transfer-expression AST and each modifier-state
AST (all targets, including disabled edges) in the private edge-ID-keyed `Scenario` bundle, and
exclude inactive state-edge transfer/nonmodifier control strings. Confirm `compile_checked`
consumes/moves the bundle into edge-indexed 037 slots with no parse in plan/simulator/engine code,
no missing/unconsumed entry, no public AST exposure, and unchanged error timing/evaluation.

You may make narrow corrections within task scope, rerun affected focused tests, and then rerun the
full gates. Any contract change or broad redesign must be rejected back to the owning task.

## DoD

- Every R001-R015 acceptance anchor is inspected and linked to passing evidence.
- Public API and rustdoc are coherent for downstream callers on MSRV 1.85.
- Public API tests compile every frozen constructor/setter/default signature verbatim and establish
  the final desugaring surface for spec 040.
- Existing serde semantic values and legacy compile entrypoints are preserved.
- Parsed-DTO semantic value is the fixture baseline; raw alias/default spelling is not promised.
- Invalid key/tag/payload/target/zero/duplicate cases fail at deterministic paths.
- Valid DTO and checked paths converge and produce equal full reports.
- No engine fallback or public raw-validation escape bypasses checked plan values.
- Every active formula AST is parsed once, retained privately, moved into the correct plan slot,
  and borrowed by execution without reparsing or public exposure.
- All focused and full validation commands pass from the final tree.
- The independent review records no unresolved finding; otherwise completion is refused.

## Escalate If

- Any existing serde value, valid deterministic report, 037 facade method, or module privacy
  contract changed.
- Any checked enum/config/builder family or metadata operation is incomplete.
- An invalid state can reach plan assembly or an engine fallback still repairs it.
- A formula is parsed more than once, a required AST is missing/unconsumed, inactive formula text is
  parsed contrary to the contract, or `CompiledExpr` leaks publicly.
- A narrow fix cannot resolve a review finding within task scope.
- The validator is not independent from the implementation workers.
