## Escalate If

- Adding `trybuild` would overwrite unrelated `Cargo.toml` or `Cargo.lock` changes.
- A diagnostic cannot be focused without unstable spans or a second public macro.
- `#![no_implicit_prelude]` or actual Cargo rename reveals a private/literal path dependency that
  cannot be fixed with `$crate` and public APIs.
- Snapshot stability would require freezing arbitrary compiler type errors rather than owned
  grammar errors.
- A complete pass fixture exposes a missing grammar category or repeated expression evaluation
  that cannot be corrected within the existing contract.
