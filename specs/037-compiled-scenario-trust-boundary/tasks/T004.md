## Context

T001 has made identifier Serde checked. T002/T003 have established the final immutable plan and
removed per-run expression/routing construction. This task is the atomic productionization and
0.2 public-contract gate; downstream specs depend on this exact task ID.

Finalize the supported surface:

- `src/lib.rs` uses private `mod plan`, `mod validation`, `mod engine`, and `mod batch`;
- root and `src/prelude.rs` re-export `CompiledScenario`;
- `Simulator::{compile,run,run_batch,...}` is the public execution facade;
- `TryFrom<ScenarioSpec>` remains the checked conversion;
- accessors remain exactly `scenario_id`, `source_spec`, `node_ids`, `edge_ids`, `node_count`, and
  `edge_count` with the frozen return types;
- raw compiler/engine/batch items are private or `pub(crate)`, not exposed under an `advanced`
  alias.

Migrate every listed integration test, testkit helper, parity diagnostic, benchmark, README snippet,
and drift test from raw modules/direct fields to the facade/accessors. Update `CHANGELOG.md`
Unreleased and README with exact old-to-new paths. Do not own the aggregate Cargo version bump or
publication.

Remove every temporary compatibility re-export/adapter/deprecation shim introduced to keep earlier
slices green. Remove prototype/tracer wording, debug switches, `TODO`s, and stale old-path comments.
`ScenarioSpec` remains the serializable wire DTO; do not add compiled-plan Serde.

This is risky public-API/invariant work. Full validation and a fresh independent Sol/high review are
mandatory. A Luna closeout cannot satisfy review.

  longer public API.
- Root/prelude `CompiledScenario`, `Simulator`, `TryFrom`, and all six accessor signatures match the
  frozen contract.
- No temporary validation re-export, advanced/raw alias, unchecked constructor, mutable plan
  access, interior mutability, or compiled-plan Serde remains.
- All listed repository consumers use the final facade/accessors; repository searches for old raw
  paths/direct compiled fields return no supported-code matches.
- README and changelog give exact migration examples and rustdoc/README drift tests pass.
- Identifier wire tests, public plan tests, deterministic/parity/event/artifact/testkit tests, and
  sequential/Rayon behavior all pass.
- Formatting, all-feature Clippy, all-target/default/parallel/all-feature tests, rustdoc, and
  Criterion smoke complete successfully.
- A fresh Sol/high validator approves the complete final diff and confirms T004 is safe as the
  predecessor contract for specs 038 and 039.
