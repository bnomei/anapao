## Context

Add private `src/plan.rs` as the sole representation owner. The durable public contract is an
opaque `CompiledScenario(Arc<ExecutionPlan>)` with no public fields or unchecked constructor and
these exact methods:

```rust
pub fn scenario_id(&self) -> &ScenarioId;
pub fn source_spec(&self) -> &ScenarioSpec;
pub fn node_ids(&self) -> &[NodeId];
pub fn edge_ids(&self) -> &[EdgeId];
pub fn node_count(&self) -> usize;
pub fn edge_count(&self) -> usize;
```

Implement `TryFrom<ScenarioSpec, Error = SetupError>` and make `Simulator::compile` delegate to it.
The private compiler in `src/validation/mod.rs` remains the only plan assembler and preserves its
current validation/error order.

`ExecutionPlan` owns the canonical source DTO plus deterministic `Box<[CompiledNode]>` and
`Box<[CompiledEdge]>`, private ID lookup maps using distinct `NodeIndex`/`EdgeIndex` newtypes, and a
metric projection. `CompiledNode`/`CompiledEdge` hold the immutable runtime fields currently read
from source maps, including resolved endpoint indexes. Use collection keys as runtime identity;
key-versus-embedded-ID rejection belongs to the dependent checked-authoring spec.

Migrate engine/batch core reads to narrow crate-private plan queries. Remove invariant `expect`,
skip, zero, and default branches whose only cause is a compiled order/index/source mismatch. Keep
RNGs, values, queues, reports, captures, and event state per run. The plan has no locks, cells, lazy
cache, or mutable accessor.

T003 owns expression/routing retention. It is acceptable for the existing per-run expression and
routing builders to remain in this independently green slice. Existing raw module paths may also
remain temporarily so integration suites compile; if the moved type needs a compatibility
re-export, make it clearly transitional for mandatory T004 removal. Do not use tracer/prototype
names in surviving code.

Because field opacity immediately breaks direct consumers, migrate the listed README, benchmark,
Pikmin, parity-diagnostic, and README-test field reads to the frozen accessors in this task.

## DoD

- `src/plan.rs` owns an opaque single-`Arc` public handle and private immutable plan components.
- `CompiledScenario` derives/implements `Debug`, cheap `Clone`, and value `PartialEq`; a unit test
  proves clones share one `Arc` allocation.
- A compile-time test proves `CompiledScenario: Send + Sync`; no plan interior mutability exists.
- `TryFrom<ScenarioSpec>` and `Simulator::compile` share one checked compiler; no downstream
  unchecked constructor exists.
- Deterministic node/edge slices, typed indexes, resolved endpoints, and metric projection are built
  after existing validation and tested for alignment/equality.
- Engine/batch core paths borrow immutable plan projections and no longer rejoin independently
  mutable public source/order/index fields.
- Every listed direct-field consumer uses accessors and the repository remains buildable.
- Per-run expression/routing builders are the only explicitly deferred plan work; all other final
  production names/contracts are in place.
- Focused and all-target validation is green, followed by fresh independent Sol/high review.
