## Context

`ScenarioId`, `NodeId`, `EdgeId`, and `MetricKey` are generated by one macro. The newtypes have a
private `String`, transparent string serialization, and checked `new`/`TryFrom<String>` paths that
reject trimmed-empty and control-character values. Derived `Deserialize` currently constructs the
private field directly and bypasses those checks.

Keep derived transparent `Serialize`. Remove derived `Deserialize` and generate a manual
`Deserialize<'de>` implementation through the same macro: deserialize `String`, call the existing
`TryFrom<String>` (therefore `new()`), and map `IdentifierError` with
`serde::de::Error::custom`. Do not duplicate validation logic or change error variants.

The valid wire contract remains a JSON string in scalar, value, and `BTreeMap` key positions.
Cover all four newtypes, not one representative. This is a persisted public boundary and requires a
fresh independent Sol/high review after tests pass.

## DoD

- All four identifier types route Serde input through their existing checked conversion.
- Whitespace-only and escaped control-character JSON values are rejected for every identifier.
- Valid scalar identifiers serialize/deserialise as the same JSON strings.
- A representative `ScenarioSpec` round trip proves IDs remain compatible as map keys and embedded
  values.
- No validation rule, wire wrapper/object, public constructor, or identifier error class changes.
- Formatting and focused tests are green and an independent Sol/high validator approves the diff.

## Validation

```bash
cargo fmt --all -- --check
cargo test --lib identifiers
cargo clippy --lib --all-features -- -D warnings
```

After commands pass, request a fresh Sol/high validator. It must inspect the generated code for all
four macro expansions, confirm valid JSON shape/map-key compatibility, and confirm no alternate
unchecked `Deserialize` path remains.

## Escalate If

- Valid identifier JSON changes shape or a `ScenarioSpec` round trip fails.
- Existing persisted fixtures contain an intentionally supported empty/control identifier.
- Serde map-key handling cannot use the same checked `String` conversion without a compatibility
  change.
